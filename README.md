## 📂 Projects

### 1. [📄 Resume Analyser](./Resume_Analyser)
An AI-powered candidate screening and resume evaluation engine built with **Streamlit**, **Python**, **scikit-learn**, and **Google Gemini AI**.
- **Multi-Format Ingestion:** Supports PDF, DOCX, and TXT resumes & job descriptions.
- **Hybrid Matching Engine:** Evaluates skill alignment, TF-IDF semantic cosine similarity, and ATS section structure.
- **Interactive UI & Batch Ranking:** Single resume deep-dive and multi-resume candidate screening leaderboards.
- **AI-Powered Review:** Optional SWOT analysis, resume tailoring suggestions, and customized interview question generator.

---

## 🛠 Tech Stack Overview

- **Languages:** Python
- **Frontend / Dashboards:** Streamlit
- **NLP & Machine Learning:** scikit-learn, TF-IDF Vectorization, pypdf, python-docx
- **Generative AI:** Google Gemini API (`google-genai`)
- **Developer Experience:** Modular architecture, automated unit tests, and CLI runner
